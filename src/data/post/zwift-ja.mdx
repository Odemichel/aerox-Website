## はじめに

10年以上にわたり、Zwiftはインドアサイクリングをバーチャルな遊び場に変えてきました。冬のあいだ何千人ものサイクリストやトライアスリートのモチベーションを支え、トレーニングをソーシャルでゲーム感覚の体験にしてくれるプラットフォームです。

AeroXが答えるのは別の問いです。バーチャルの世界に連れて行くのではなく、**あなたの実際のポジションを測定**します。一般的なWebカメラだけで、体のポジションによって前面投影面積がどう変わり、それがスピードにどれだけ損得をもたらすかをリアルタイムで示します。

2つのツール、2つの目的。それぞれが何をするのか、Zwiftがどこまでなのか、そしてAeroXがすでにお使いのアプリをどう補完するのかを解説します。

---

## Zwiftはインドアサイクリストに何を提供するのか？

Zwiftはゲーム感覚のインドアサイクリングプラットフォームです。世界中の何千人ものサイクリストと一緒に走り、グループライドに参加し、ライブでレースをし、構造化されたトレーニングプランに沿って練習できます。最大の強みは、冬のあいだのモチベーションと継続性です。

体験は高度にゲーム化されています。バッジ、XP、アンロックできるバーチャルのバイクやホイール、探索できるルート。ベース持久力からVO2maxインターバルまで、Zwiftは段階的に成長するための環境を一通り備えています。

スピードを計算するために、Zwiftはあなたの体重、身長、他のライダーの後ろでのドラフティング、そして選んだバーチャル機材（フレーム、ホイール）をモデル化します。モデル化していないのは、**バイク上の実際のポジション**です。上体を起こしていても、深く伏せていても、同じワット数なら同じスピードになります。

屋外でレースを走るトライアスリートやサイクリストにとって、これが欠けているピースです。レース当日に保つポジションこそ、インドアトレーニングが決して測定しないものなのです。

---

## AeroXは何を測定するのか？

**AeroXは、一般的なWebカメラでサイクリストの前面投影面積をリアルタイムで測定するインドアトレーニングソフトウェア**です。前面投影面積（A）は、空気抵抗のうちポジションで自分がコントロールできる部分です。AeroXはポジションの変化を、スピードとワットへの影響に換算します。一般的に観測される効果は、同じパワーで2〜3 km/hのスピードアップです。

> **前面投影面積（A）**：正面から見たサイクリストの体の投影面積（m²）。空気抵抗はCdA = Cd × Aで決まります。前面投影面積が小さいほど空気抵抗は小さくなり、同じパワーでより速く走れます。

ペダルを回し始めるとすぐに、AeroXはWebカメラで前面投影面積を測定し、パワーと勾配と組み合わせて現実的なスピードを計算します。姿勢を変えるたびに、何を失い何を取り戻すのかが目で見えて、体で感じられます。

### AeroXのトレーニングモード

- 目標速度モード：ポジションに応じてトレーナーが負荷を調整し、目標速度を維持します。姿勢がパフォーマンスにどう影響するかを直接体感できます。
- フリーシミュレーションモード（GPX）：パワー、勾配、風、ポジションによってスピードが決まる実在のルートを走り、レースやヒルクライムに備えます。
- テクニックモード：ポジションを比較し、コックピットのセッティングを試して、エアロ効果をその場で確認できます。
- エアロタイムトライアルモード：パワーウェイトレシオだけでなく、パワーとエアロダイナミクスの両方で結果が決まるレースです。
- ワークアウトビルダー：パワーとエアロの目標を設定した構造化セッションを作成できます。

AeroXはZwiftのソーシャルな面と張り合うつもりはありません。Zwiftが測定しないもの、つまり実際のポジションへのリアルタイムフィードバックを加えるのです。

---

## ZwiftとAeroX：それぞれの役割

**Zwiftは実際のポジションが影響しないバーチャルの世界をシミュレートし、AeroXはそのポジションを測定してスピードへの影響を示します。** Zwiftはモチベーションとコミュニティに、AeroXはポジションづくりに優れています。両者はうまく組み合わせられます。

| | Zwift | AeroX |
|---|---|---|
| 主な目的 | モチベーション、コミュニティ、レース | エアロポジションの測定とトレーニング |
| スピードモデル | 体重、身長、ドラフティング、バーチャル機材 | 測定した前面投影面積、パワー、勾配 |
| 実際のライディングポジション | モデル化されない | Webカメラでライブ測定 |
| 構造化ワークアウト | あり | あり（エアロ目標付き） |
| ルートシミュレーション | バーチャルワールド | 実在のGPXルート |
| コミュニティ・オンラインレース | 非常に充実 | 開発中 |
| トレーナー接続 | ANT+またはBluetooth | Bluetooth FTMSのみ |
| 対応デバイス | パソコン、タブレット、スマートフォン、Apple TV | MacまたはWindowsのパソコン |

## 組み合わせ方

グループライド、レース、モチベーションにはZwiftを。ポジションに取り組むセッションにはAeroXを使いましょう。最速のポジションを見つけ、それを維持できるようにトレーニングします。時速35 kmで2〜3 km/h速くなれば、**40 kmで約4〜5.5分の短縮**になります。1ワットも余分に出す必要はありません。

Zwiftはモチベーションとエンジンを鍛えます。AeroXは、そのワットをスピードに変えるポジションを測定し、鍛えます。両者は競合ではありません。**AeroXは、Zwiftがモデル化しないものを測定する補完ツールです**。
